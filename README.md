# ESP-Camera
Okay so this is basically a hand held camera that you can use to capture pictures and as per the name yes it uses ESP32 S3 to make the work happen! It has two parts one transmitter and one receiver so yea! u can capture pictures with the transmitter and then just wirelessly export the picture from the receiver but i have made the case like u can use both of them in a single case but yea! u can just use it wirelessly too! so yea! 

# Why did i made this?
i do have a camera that i bought from shenzhen china yes i went to fallout but i always wanted to make my own handheld camera and also i have to complete my horizons hours for stipend so im just making stuff that i wanted to make!
